OPTO GLOW by ROHIT JI - Windows VST3 install
=====================================

1. Copy the folder  "Opto Glow.vst3"  into:
       C:\Program Files\Common Files\VST3\

2. FL Studio:
   Options > Manage plugins > Find more plugins (or "Find installed plugins")
   Then add it from the Mixer: Insert slot > Select > "Opto Glow"

3. Cubase:
   Studio > VST Plug-in Manager > Rescan (or just restart Cubase)
   It appears under Dynamics > "Opto Glow"

Tips
- Double-click any knob to reset it.
- Drag the bottom-right corner to make the window bigger.
- GR / IN / OUT buttons switch what the VU meter shows.
